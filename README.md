# LawAssistant-Frontend
Репозиторий содержит веб-клиент системы анализа степени соответствия коллективного договора действующему закодательству

## Структура репозитория
- **src/**
  - **assets/** - статические файлы компонентов
  - **components/** - компоненты интерфейса
  - **pages/** - страницы
  - **api/** - клиент API бэкенда
- **public/** - статические файлы приложения

## Быстрый запуск
### Запуск API
``` bash
npm start
```
